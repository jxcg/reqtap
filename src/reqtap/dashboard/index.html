reqtap

The dashboard is mounted. The live feed UI is not built yet.

The JSON API backing it is live now:

  • GET /_reqtap/api/requests: captured requests, newest first
  • GET /_reqtap/api/requests?since=<id>: only what is newer than id
  • GET /_reqtap/api/requests/<id>: full detail for one request
  • DELETE /_reqtap/api/requests: clear the buffer
